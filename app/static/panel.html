Source settings

Set the browser source like this.

    Steps

    Two minutes, once.

    1. Sources → + → Browser. Paste the URL, set width and height, leave the custom CSS empty.
    2. Tick Control audio via OBS so the TTS gets its own track in the Audio Mixer.
    3. Turn off "Shutdown source when not visible" and "Refresh browser when scene becomes active", so the connection stays up.
    4. Open the Live tab and press Speak: you should hear the voice and see the caption.
